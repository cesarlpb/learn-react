## Crear proyecto de React

❌ Forma no recomendada (es más lento): `npx create-react-app`

## Vite 

`vite` es un gestor de comandos para crear proyectos de JS, React, etc.

- Instalar vite con:

```
  npm install --global create-vite
```

- Crear proyecto de React:

✅ Forma recomendada: `npm create vite@latest`

Elijo `react-vite` como nombre, `React` y `Javascript`:

```
  cd react-vite
  npm install
  npm run dev
```
